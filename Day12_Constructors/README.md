# 🔥 Key Concepts

## Default Constructor

```java
class Student {

    Student() {
        System.out.println("Constructor Called");
    }
}
```

## Parameterized Constructor

```java
Student(String name) {
    this.name = name;
}
```

## Constructor Overloading

```java
Student() {
}

Student(String name) {
}
```
