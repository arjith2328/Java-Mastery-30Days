# 🔥 Key Concepts

## Matrix Declaration

```java
int[][] matrix = {
    {1,2,3},
    {4,5,6},
    {7,8,9}
};
```

## Accessing Elements

```java
matrix[1][2]
```

Output:

```text
6
```

## Matrix Traversal

```java
for(int i = 0; i < matrix.length; i++){

    for(int j = 0; j < matrix[i].length; j++){

        System.out.print(matrix[i][j] + " ");
    }
}
```
