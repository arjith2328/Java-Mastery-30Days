# 🔥 Key Concepts

## Switch Syntax

```java
switch(choice){

    case 1:
        System.out.println("Option 1");
        break;

    case 2:
        System.out.println("Option 2");
        break;

    default:
        System.out.println("Invalid Choice");
}
```
