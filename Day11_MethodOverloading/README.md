# 🔥 Key Concepts

## Method Overloading

```java
static int add(int a, int b){
    return a + b;
}

static int add(int a, int b, int c){
    return a + b + c;
}
```

## Different Data Types

```java
static void show(int num){
    System.out.println(num);
}

static void show(double num){
    System.out.println(num);
}
```
