# 🔥 Key Concepts

## Simple Method

```java
static void greet() {
    System.out.println("Hello");
}
```

## Method with Parameters

```java
static void greet(String name) {
    System.out.println("Hello " + name);
}
```

## Return Method

```java
static int add(int a, int b) {
    return a + b;
}
```

## Method Call

```java
greet();
add(10, 20);
```
