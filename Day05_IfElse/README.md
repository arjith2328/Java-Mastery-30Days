# 🔥 Key Concepts

## Simple If

```java
if(age >= 18){
    System.out.println("Eligible");
}
```

## If Else

```java
if(num % 2 == 0){
    System.out.println("Even");
}
else{
    System.out.println("Odd");
}
```

## Else If Ladder

```java
if(marks >= 90){
    System.out.println("Grade A");
}
else if(marks >= 75){
    System.out.println("Grade B");
}
else{
    System.out.println("Grade C");
}
```
